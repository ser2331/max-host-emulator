# Changelog

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).
Версии: [SemVer](https://semver.org/lang/ru/).

`0.1.0` — базовый пригодный стенд для тестирования миниаппа на web / desktop / android / ios.

## [0.1.1] — 2026-08-18

### Changed

- Исправлен независимый скролл панели настроек и лога
- Биометрия и NFC теперь ближе к state machine реального клиента: появились ветки `not_supported`, `permission_denied`, `not_found`, `not_enabled`, `access_revoked`

## [0.1.0] — 2026-08-18

### Added

- Независимые скроллы панелей: длинные настройки и лог больше не прокручивают центральную сцену
- Настройки разбиты по группам и сворачиваются
- Сцену хоста можно использовать как постоянный тестовый стенд для четырёх платформ

## [0.0.5] — 2026-08-17

### Added

- Полный initData в хеше: `chat` и `user.photo_url`
- Автосохранение настроек стенда в localStorage
- Появились поля `userId`, `photoUrl`, `chatId`, `chatType` в UI

## [0.0.4] — 2026-08-17

### Added

- Нативные шиты: разрешить / отказать / ошибка для телефона, share, QR, скачивания, биометрии и NFC
- Режим шитов: спрашивать, всегда разрешать, всегда отказывать
- Состояние биометрии и NFC на платформе, сброс из панели

## [0.0.3] — 2026-08-17

### Changed

- Ответы Bridge приведены к доке и к `max-web-app.js`: `entryPoint`, viewport строками, `requestContact` с `authDate`/`hash`
- DeviceStorage и SecureStorage разделены; у SecureStorage лимит 10 ключей
- Неизвестные методы отвечают `{ error }`, а не успехом
- Яркость, скриншоты и свайпы возвращают поля, которые читает официальный bridge

## [0.0.2] — 2026-08-17

### Added

- Профили платформ: chrome, `deviceName`, версия клиента и матрица методов для web / desktop / android / ios
- Отказ Bridge-методов, которые на выбранной платформе не поддерживаются
- Хранилище хоста разделено по платформам

## [0.0.1] — 2026-08-17

### Added

- Каркас хоста: iframe миниаппа, HTTPS Vite, подпись `initData`
- Часть MAX Bridge: close, BackButton, storage, openLink, download, haptic no-op, viewport, share/QR/phone-заглушки
- Переключатель платформы в UI (пока почти не влияет на поведение)
- Лог bridge-событий и проверка документации Bridge
- Имя продукта **MAX Host**, версия в UI
